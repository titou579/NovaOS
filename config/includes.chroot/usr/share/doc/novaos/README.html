Bienvenue sur NovaOS

NovaOS est un système libre construit sur Debian et le bureau XFCE.

Pour commencer

  • Ouvre le navigateur depuis le menu Applications.
  • Utilise le raccourci ChatGPT pour accéder au site officiel.
  • Ouvre Paramètres du système pour personnaliser le bureau.
  • Installe les mises à jour régulièrement.

Conseils de sécurité

  • Garde les mises à jour automatiques activées.
  • Ne lance pas de fichiers inconnus.
  • Pour les expériences en machine virtuelle, crée un instantané avant les changements.
  • Ne partage pas les dossiers de ton ordinateur hôte avec une VM de test.

NovaOS ne crée aucun compte en ligne à ta place. Crée ton compte utilisateur pendant l'installation et protège-le avec un mot de passe unique.
